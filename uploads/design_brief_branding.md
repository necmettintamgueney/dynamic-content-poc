# Delivery Hero Branding Package

## Logo

The DH icon logo is included as `dh-logo.svg` (red arrow/marker icon). Use it in the header or as a favicon. The icon color is DH Red (#C3242C).

For the wordmark, use "Delivery Hero" or "DH" in Outfit Bold alongside the icon.

## Typography

**Primary font: Outfit** (Google Fonts: https://fonts.google.com/specimen/Outfit)

Weights used on deliveryhero.com:
- **Outfit Regular (400)** -- body text, descriptions
- **Outfit SemiBold (600)** -- subheadings, labels, navigation
- **Outfit Bold (700)** -- headings, hero text, emphasis

No secondary font needed. Outfit covers all uses (headings, body, UI elements).

## Visual Style (from deliveryhero.com)

- **Clean and modern.** Generous whitespace, flat design, no gradients on UI elements.
- **Card-based layouts.** Content organized in rounded-corner cards with subtle borders.
- **Bold headings, concise body text.** Headlines are large Outfit Bold, body is smaller Regular weight.
- **Red as accent, not dominant.** DH Red is used for CTAs, active indicators, and key emphasis points. Most of the page is neutral.
- **Rounded corners.** Buttons and cards use 8-12px border radius.
- **Font sizes from deliveryhero.com:**
  - Small: 13px
  - Medium: 20px
  - Large: 36px
  - X-Large: 42px

## Design Preferences

- The designer can choose light or dark theme (or both). Both palettes are provided above.
- For a leadership audience, prefer light theme with dark text for readability on projector screens. Dark theme works better for screen-based viewing.
- Avoid overusing DH Red. It should feel premium and intentional, not aggressive.
