From Open Loop to Closed Loop

The content process today is an open loop. Each stage runs without informing the next, and almost nothing flows back. The strategy closes it: budget is known before design, investment scales with value, quality is a defined target, the right model is always running, and production problems are detected and fixed in days.

Six Failure Points

P1

Budget Unknown

We design a content solution before we know what it is allowed to cost. Effort goes into options that were never viable.

P2

Uniform Spend

A product going to one small local vendor receives the same investment as a product going live across a strategic partner.

P3

Slow Evaluation

Without a defined quality target, evaluation is slow and subjective. Adopting a new model is a separate development project every time.

P4

No Observability

We learn about quality problems weeks later through correction data, if at all. Production is largely unobserved.

P5

Slow Reaction

Even once a problem is known, shipping a fix is another development cycle. Detection to resolution is measured in months.

P6

Minor Fixes Ignored

Small, recurring issues never reach the top of a backlog. The "add 1 Piece" pattern (19-34% of corrections) persists indefinitely.

Roadmap & Sequencing

Pillars are sequenced by dependency. Each phase builds on the last. A reliable baseline must precede tiering; acceptance criteria must precede model selection.

Phase 0 — Foundations

The Floor

Define acceptance criteria and the health standard. Fix the critical model gaps: auto-publish threshold, APAC format, Spanish extraction, attribute storage, the "add 1 Piece" rule. Stand up the correction-pair dataset.

Pillar 3 Pillar 4 start Pillar 6 start
Phase 1 — Differentiated Investment

Tiering + Guidelines + Model Store MVP

Tiering live. Granular guidelines for top categories and experimentation capability. Model Store MVP: access layer and registry with assisted selection. Inline QA gate live.

Pillar 1 Pillar 4 Pillar 5 MVP Pillar 6 inline
Phase 2 — Intelligence

ROI + Autonomous Model Selection + Monitoring

ROI override live. Model Selection Agent running autonomously. Monitoring QA agents in detect-and-report mode.

Pillar 2 Pillar 5 auto Pillar 6 monitor
Phase 3 — Closed Loop

Herogen + Self-tuning

Herogen automated improvement with risk-based autonomy. Self-tuning model assignment, guidelines, and ROI estimates across the catalog.

Pillar 6 full Self-learning

Critical Dependencies

▸ Reliable baseline (Phase 0) must precede tiering
▸ Acceptance criteria (Pillar 4) must precede Model Selection Agent
▸ Inline QA must precede monitoring QA
▸ Monitoring QA must precede Herogen
▸ Experimentation capability needed before guideline tuning
